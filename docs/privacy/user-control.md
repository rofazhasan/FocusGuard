# Privacy: User Control & Data Rights

FocusGuard grants full data sovereignty to the account owner.

---

## 1. Right to Access & Export
Users can query and export all stored usage aggregates and audit events via the REST API (`GET /api/v1/analytics/weekly`, `GET /api/v1/audit/logs`).

---

## 2. Right to Erasure
Deleting a policy or unregistering a device immediately clears all associated foreign keys from the database.
