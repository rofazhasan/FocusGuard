# Privacy: Data Collection Practices

FocusGuard adheres to **purpose limitation** and **data minimization**.

---

## 1. Local Processing First
- URL path stripping occurs **on-device** before any data is sent over the network.
- Subdomain categorizations are resolved using local lookups.

---

## 2. No Third-Party Analytics / Telemetry
- FocusGuard contains zero third-party advertising SDKs, tracking pixels, or third-party cloud analytics libraries.
- All telemetry stays strictly between the enrolled device and the user's FocusGuard server.
